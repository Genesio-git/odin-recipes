Odin Recipes 🍽️

Site de receitas culinárias desenvolvido com HTML puro.

📖 Sobre o projeto

Página inicial com listagem de receitas que levam a páginas individuais, cada uma contendo foto do prato, descrição, lista de ingredientes e modo de preparo. Receitas incluídas: Pizza, Feijoada e Strogonoff.

🗂️ Estrutura do projeto


```
odin-recipes/
├── index.html
├── recipes/
│   ├── pizza.html
│   ├── feijoada.html
│   └── strogonoff.html
└── images/
    ├── pizzazuda.jpg
    ├── feijoada.jpg
    └── strogonoffzada.jpg
```

🛠️ Tecnologias utilizadas


HTML5


📚 Contexto

Projeto desenvolvido como parte do currículo The Odin Project — Foundations.
